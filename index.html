🧭 Comment utiliser un dépôt GitHub ? (2 min)
📦 AppUne vraie application à installer. Va dans Releases du dépôt, ou en une ligne : brew install --cask nom
⌨️ Ligne de commandeUn outil qu'on tape dans le Terminal. Copie la commande affichée sur la carte (bouton Copier) et colle-la.
🏠 Auto-hébergéUn service qui tourne chez toi (Mac, mini-PC) via Docker. Installe OrbStack ou Docker Desktop, puis la commande indiquée.
🧩 BibliothèqueUne brique pour coder tes apps. Le plus simple : demande à ton agent T3 « utilise <nom> dans mon projet ».
🔌 ExtensionUn module pour un logiciel existant (Obsidian, Zotero, navigateur, Claude Code).
📋 ListeRien à installer : une page de référence à parcourir et à garder en favori.
🟢🟡🔴 Niveau🟢 Facile = télécharger · 🟡 Moyen = terminal/Docker · 🔴 Avancé = code Python/JS.
★ ÉtoilesLes « likes » de GitHub : plus il y en a, plus le projet est populaire, maintenu et fiable.
